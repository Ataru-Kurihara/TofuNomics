# TofuNomics - あなただけの職業で、サーバーに貢献しよう

> **ただ掘るだけ、ただ建てるだけじゃない。あなたの「役割」がここにある。**

## 🎯 TofuNomicsとは？

TofuNomicsは、Minecraftに「職業」と「経済」の概念を導入する革新的なプラグインです。

8つの専門職業から1つを選び、スキルを磨いて、お金を稼ぎ、サーバーのコミュニティに貢献する——そんな新しいMinecraft体験を提供します。

### このプラグインが実現すること

- 🎭 **あなただけの役割**: 全員が同じことをするのではなく、職業ごとに異なる専門性
- 💼 **働く楽しさ**: 作業が経験値と収入に直結する達成感
- 🤝 **助け合いの経済**: お互いに必要とし合う、プレイヤー間の相互依存
- 📈 **成長の実感**: レベル100まで続く、長期的な育成要素
- 🏘️ **豊かな生活**: 稼いだお金で住居を借り、快適な拠点作り

## 🎮 できること - 主要機能

### 👨‍💼 8つの専門職業から選んで成長

あなたの好きなプレイスタイルに合わせて職業を選択できます。

#### 安定収入タイプ
- **🌾 農家** - 作物栽培と動物繁殖で安定した収入を確保
  - 💡 自動収穫スキル、種自動補充
  - 初心者におすすめ、コツコツ型プレイヤー向け

- **🪓 木こり** - 木材を供給して建築を支える
  - 💡 苗木自動植樹、伐採範囲拡大
  - 自然が好き、建築サポートしたい人向け

#### 一攫千金タイプ
- **⛏️ 鉱夫** - 貴重な鉱石を掘り当てて高収入
  - 💡 鉱石発見率アップ、幸運効果
  - 冒険好き、リスクを取って稼ぎたい人向け

- **🎣 釣り人** - レアな魚や宝物を釣り上げる
  - 💡 宝物発見、レア魚確率アップ
  - のんびり派、運試しが好きな人向け

#### クラフト・生産タイプ
- **🔨 鍛冶屋** - ツール、武器、防具を生産・修理
  - 💡 耐久力向上、修理効率アップ
  - 装備品の製造で他プレイヤーをサポート

- **⚗️ 醸造師** - ポーションを醸造して販売
  - 💡 ポーション効果延長、材料節約
  - 薬品製造で冒険者を支援

- **✨ エンチャンター** - エンチャントサービスを提供
  - 💡 エンチャント成功率アップ、レア効果
  - 魔法付与のスペシャリスト

#### 建築・装飾タイプ
- **🏗️ 建築家** - 美しい建築物を作り上げる
  - 💡 専用装飾ブロック、建築効率アップ
  - クリエイティブ派、美的センスを発揮したい人向け

### 📈 レベル100までの成長システム

#### レベルアップの流れ
1. **作業をする** → 職業に応じた作業（採掘、収穫、釣りなど）
2. **経験値を獲得** → 作業量に応じて自動で経験値が貯まる
3. **レベルアップ** → 収入アップ＋新スキル解放

#### レベルによる恩恵
| レベル帯 | 収入倍率 | 解放されるもの |
|---------|---------|-------------|
| Lv.1-10 | 1.0倍 | 基本的な作業のみ |
| Lv.11-25 | 1.5倍 | 基本スキル解放 |
| Lv.26-50 | 2.0倍 | 中級スキル解放 |
| Lv.51-75 | 3.0倍 | 上級スキル解放 |
| Lv.76-100 | 4.0倍 | マスタースキル解放 |

#### 転職も可能
- レベル50に到達すれば、別の職業に転職できます
- レベルは保持されるので、新しい職業でも即戦力！

### 💰 働いて稼いで、豊かな生活

#### お金の稼ぎ方
1. **NPC取引所で売却** - 職業に応じたアイテムを高値で売却
   - 職業ボーナス適用で通常より高く売れる！
   - 営業時間: 6:00-22:00
   
2. **取引チェストで自動売却** - チェストに入れるだけで自動売買
   - レベルが高いほど高値で売れる
   - 24時間いつでも利用可能

3. **プレイヤー間取引** - 他のプレイヤーと直接取引
   - `/pay` コマンドで簡単送金
   - 物々交換や代行サービスも

#### お金の使い道
- **住居を借りる** - 安全な住居エリアを賃貸
- **アイテムを購入** - 食料NPCや加工NPCを利用
- **他プレイヤーに発注** - 建築や装備製作を依頼
- **資産ランキング** - `/baltop` で富豪を目指す

### 🏪 便利なNPCシステム

#### 銀行NPC - お金の管理
- 💰 金塊アイテムと銀行残高を相互変換
- 📊 残高確認・預金・引出がいつでも可能
- 🏧 ATMも利用可能（主要エリアに設置）

#### 取引NPC - アイテムの売買
**職業別取引所**
- 職業に応じたアイテムを高値で買取
- 職業ボーナス価格適用
- 専門職なら断然お得！

**総合取引所**
- どの職業でも利用可能
- あらゆるアイテムを買取
- 職業未加入でもOK

#### 食料NPC - 緊急時の食料供給
- パン、肉、魚などを販売
- 営業時間: 6:00-22:00
- 1日32個まで購入制限（農家保護）

#### 加工NPC - 便利な素材加工
- 原木 → 板材に変換（4個 → 16個）
- 木こりは無料、一般プレイヤーは1G/原木
- 24時間営業

### 🏠 住居賃貸システム - 自分の拠点を

#### こんな物件が借りられる
- 運営が用意した建築物を期間制で賃貸
- 安全な住居エリア（WorldGuard保護）
- 敵対的モブの自動除去で快適生活

#### 料金プラン
```
日額プラン - 基本料金
週額プラン - 日額 × 6.5日分（約7%お得！）
月額プラン - 日額 × 25日分（約17%お得！）
```

長く借りるほどお得な料金設定です。

#### 使い方
```
/housing list              # 物件一覧を確認
/housing rent 1 1m         # 物件#1を1ヶ月借りる
/housing myrentals         # 自分の契約を確認
/housing extend 1 7        # 契約を7日間延長
```

## 💭 よくある質問

### Q1: 職業は変更できますか？
**A:** はい、レベル50に到達すれば転職可能です。レベルは保持されるので、新しい職業でも即戦力として活躍できます。

### Q2: どの職業が一番稼げますか？
**A:** 職業による収入差は意図的に小さく設計されています。どの職業も、プレイスタイルとレベルによって十分な収入を得られます。
- **安定型**: 農家、木こり（コツコツ型）
- **変動型**: 鉱夫、釣り人（運と冒険型）
- **生産型**: 鍛冶屋、醸造師、エンチャンター（クラフト型）
- **建築型**: 建築家（クリエイティブ型）

### Q3: 初心者でも楽しめますか？
**A:** もちろんです！初心者には「農家」がおすすめ。安定した収入が得られ、スキルもわかりやすく、すぐに成長を実感できます。

### Q4: お金が貯まらない時は？
**A:** 以下を試してみてください：
- 職業に応じた作業をしているか確認（農家なら農作業、鉱夫なら採掘）
- NPC取引所を活用（職業ボーナスで高値売却）
- 取引チェストを設置して自動売却
- レベルを上げて収入倍率アップ

### Q5: 住居は必須ですか？
**A:** 必須ではありませんが、以下のメリットがあります：
- 安全なエリア（WorldGuard保護）
- 敵対的モブが自動除去される快適環境
- 自分だけの拠点として活用可能

### Q6: 他のプレイヤーと協力できますか？
**A:** はい、むしろ推奨されています！
- 職業が異なるプレイヤー同士で物々交換
- 自分にできない作業を他プレイヤーに依頼
- 共同プロジェクトで建築や開拓

### Q7: レベル上げは大変ですか？
**A:** 普通にプレイしているだけで自然に上がります。無理にレベル上げを意識する必要はなく、楽しく作業していればレベルアップ通知が届きます。

### Q8: スキルはどう使いますか？
**A:** 多くのスキルは自動発動です。レベルが上がると自動的に解放され、作業中に確率で発動します。意識せずに恩恵を受けられる設計です。
